# 개인정보처리방침 (초안)

상태: 초안 (2026-11-23)

> **운영자·법률 검토 전 초안입니다.** 현재 설계([DB_SCHEMA](../DB_SCHEMA.md), [SECURITY](../SECURITY.md))를 바탕으로 처리 항목을 정리한 작업용 문서이며, 개인정보 보호 관련 법령의 필수 기재사항을 모두 갖췄는지, 법령을 준수하는지는 확인되지 않았습니다. 공개 전 운영자 검토와 법률 전문가 검토가 필요합니다.
> 보유 기간 등 숫자는 모두 **제안값**입니다. `[ ]`·`BLOCKED:`·`미확인:`은 미정 항목입니다.

관련 문서: [TERMS_DRAFT](./TERMS_DRAFT.md) · [OPERATIONS §5](../OPERATIONS.md#5-개인정보-요청-처리)

## 1. 처리 목적

1. 회원 식별과 로그인 유지
2. 모임 개설·참가 신청·확정·출석 기록 등 서비스 제공
3. 신고 처리, 이용 제한, 부정 이용 방지
4. 문의·이의제기·개인정보 요청 대응

## 2. 처리하는 개인정보 항목

| 구분 | 항목 | 수집 방법 | 저장 위치 |
|---|---|---|---|
| 로그인 정보 | 소셜 로그인 제공자의 이용자 식별자, 이메일 주소, 제공자가 전달하는 경우 이름·프로필 이미지 주소 | 소셜 로그인 시 제공자로부터 | Supabase Auth(인증 시스템) |
| 공개 프로필 | 닉네임, 선호 권역, 소개, 관심 장르, 계정 상태 | 회원 입력 / 시스템 | 서비스 DB(`profiles`) |
| 비공개 계정 정보 | 약관·개인정보 동의 시각, 탈퇴 요청 시각 | 시스템 | 서비스 DB(`user_private`) |
| 이용 기록 | 개설한 모임, 참가 신청 상태·시각, 신청 시 남긴 말, 출석 기록(모임장 입력), 신고 내용과 처리 결과, 주요 행위 기록(행위 종류·시각·회원 식별자) | 서비스 이용 중 | 서비스 DB |
| 브라우저 저장 정보 | 로그인 세션 토큰, 로그인 후 돌아갈 페이지 주소 | 자동 | 이용자 브라우저(localStorage, sessionStorage) |
| 접속 정보 | IP 주소, 브라우저 정보, 요청 기록 등 | 자동 | 호스팅·DB 제공자의 로그. `미확인:` 범위와 보관 기간 |

- 이름: 서비스는 소셜 로그인 제공자가 준 이름을 닉네임이나 화면에 사용하지 않습니다. 다만 인증 시스템에는 제공자가 전달한 정보가 저장될 수 있습니다. `미확인:` 실제 저장 항목 — Google·Kakao 설정 후 확인해 이 표를 고칩니다.
- Kakao: `미확인:` 동의항목(이메일 필수 여부 등)에 따라 항목이 달라집니다.
- **수집하지 않는 정보**: 전화번호, 주민등록번호, 신분증 정보, 위치정보, 결제정보, 사진.

## 3. 다른 이용자에게 공개되는 정보

| 정보 | 공개 범위 |
|---|---|
| 닉네임, 선호 권역, 소개, 관심 장르 | 누구나(비로그인 포함) |
| 내가 개설한 모임과 그 내용 | 누구나(운영자가 숨긴 모임 제외) |
| 내 참가 신청 사실, 신청 시 남긴 말, 신청 상태 | 해당 모임의 모임장 |
| 출석 기록 | 본인, 해당 모임의 모임장, 운영자 |
| 이메일 주소 | 공개하지 않음(본인과 운영자만 확인 가능) |

모임 상세 화면에는 참가 인원 수만 보이며 참가자 닉네임 목록은 모임장에게만 보입니다.

## 4. 제3자 제공

- 운영자는 개인정보를 제3자에게 제공하지 않습니다.
- `미확인:` 법령에 따른 수사기관 등의 요청이 있을 때의 처리 기준 — 법률 검토 필요.

## 5. 보유 및 이용 기간

| 항목 | 기간(제안값, 법률 검토 필요) |
|---|---|
| 공개 프로필 | 탈퇴 요청 즉시 닉네임 "탈퇴한 사용자"로 변경, 소개·권역·관심 장르 삭제 |
| 로그인 계정과 나머지 회원 정보 | 탈퇴 요청 후 운영자가 계정을 삭제할 때까지. 처리 목표: 요청 후 [7]일 이내(제안) |
| 참가·개설 기록 | 계정 삭제 시 함께 삭제 |
| 신고·제재 기록 | 처리 완료 후 [1]년(제안). 재발·이의제기 대응 목적. 계정 삭제 후에는 대상·신고자 연결이 끊긴 상태로 남음 |
| 주요 행위 기록(감사 로그) | [1]년(제안) |
| 백업 파일 | 백업 보관 정책에 따른 기간 후 삭제. `미확인:` 제공자 자동 백업의 보관 기간 |

- `미확인:` 다른 법령에 따라 보관해야 하는 정보가 있는지(현재 결제·거래 기능 없음).

## 6. 처리 위탁과 국외 이전

| 업체 | 역할 | 처리 위치 |
|---|---|---|
| Supabase | 데이터베이스, 로그인(인증) | 프로젝트 생성 시 선택한 리전. `BLOCKED:` 미생성 |
| Cloudflare | 웹사이트 호스팅·전송 | 전 세계 네트워크 |
| Google, Kakao | 소셜 로그인(이용자가 선택한 경우) | 각 제공자 |
| jsDelivr | 글꼴 파일 전송(접속 시 IP 등이 전달될 수 있음) | 전 세계 네트워크 |

- `미확인:` 위탁·국외 이전에 대해 법령상 고지해야 하는 사항(이전 국가, 이전 일시·방법, 항목, 보유 기간, 거부 방법 등)과 동의 필요 여부 — 법률 검토 필요.
- 글꼴을 직접 호스팅하면 jsDelivr 항목을 뺄 수 있습니다(검토 중).

## 7. 파기 절차와 방법

- 보유 기간이 끝나거나 탈퇴 처리가 완료되면 운영자가 DB에서 해당 정보를 삭제합니다.
- 계정 삭제 시 연결된 프로필·참가 기록·개설 모임 기록이 함께 삭제됩니다.
- 백업 파일은 보관 기간이 지나면 삭제합니다.

## 8. 이용자의 권리와 행사 방법

- 열람·정정: 프로필 화면에서 직접 확인·수정할 수 있습니다.
- 삭제: 프로필 화면의 탈퇴 요청으로 할 수 있습니다.
- 그 밖의 열람·처리 정지 요청: 운영 이메일([이메일 주소], `BLOCKED:`)로 요청할 수 있습니다. 운영자는 요청한 계정의 로그인 이메일과 일치하는지 확인한 뒤 처리합니다.
- `미확인:` 처리 기한 — 법률 검토 필요.

## 9. 쿠키와 브라우저 저장소

- 서비스는 광고·분석용 쿠키나 추적 도구를 사용하지 않습니다.
- 로그인 유지를 위해 브라우저 저장소(localStorage)에 세션 정보를, 로그인 후 이동할 주소를 sessionStorage에 저장합니다. 로그아웃하면 지워집니다.
- `미확인:` 호스팅 제공자가 보안 목적으로 설정하는 쿠키 여부.

## 10. 안전성 확보를 위한 조치

현재 설계에 포함된 조치이며, 실제 적용과 점검 결과는 출시 전에 확인합니다.

- 데이터베이스 행 단위 접근 제어(RLS)로 본인·권한자만 정보에 접근
- 관리자 권한의 별도 부여와 관리자 작업 기록
- 서버 비밀키를 브라우저와 소스 저장소에 두지 않음
- 전송 구간 HTTPS
- 공개 프로필에 이메일·실명·전화번호를 두지 않음
