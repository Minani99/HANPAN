# 백로그 (MVP 제외 항목)

상태: 초안 (2026-11-23)

MVP에 넣지 않는 기능을 기록한다. 여기 있는 기능은 화면에서 "제공 중"인 것처럼 표현하지 않는다. 필요한 경우 "아직 준비 중이에요"처럼 사실만 안내한다.
관련 문서: [PRD §4](./PRD.md#4-mvp-범위) · [ROADMAP](./ROADMAP.md)

## 1. 제외 기능

| 기능 | 제외 이유 | 도입 전 필요한 것 |
|---|---|---|
| 알림(이메일·푸시·카카오 알림톡·문자) | 발송 인프라·비용·수신 동의 관리 필요 | 발송 수단·비용 결정, 수신 동의 정책, 개인정보처리방침 갱신 |
| 대기자 자동 승격 | 알림이 없어 자동 확정 사실을 전달할 수 없음 | 알림 기능, 확정 수락 기한 규칙 |
| 관심 알림 등록("이런 모임 생기면 알려줘요") | 알림 기능 전제 | 알림 기능 |
| 실시간 채팅·모임 단체방 | 운영·신고 부담, 개인정보 위험 | 신고·차단 체계, 보관 정책 |
| 커뮤니티 게시판 | MVP 핵심 흐름과 무관, 운영 부담 | 게시물 정책, 관리 도구 |
| 추천 AI·자동 매칭 | 데이터 부족, 설명 가능성 | 충분한 이용 데이터, 개인정보 이용 동의 |
| 제휴 예약·결제·정산·수수료 | PG 계약, 정산 책임, 법적 검토 | 사업자 결정, 계약, 법률 검토 |
| 본인확인(휴대폰·실명) | 유료 업체 계약, 민감정보 처리 | 업체 선정·비용 승인, 개인정보 영향 검토 |
| 구독·유료 상품 | 수익 모델 미정 | 사업 결정 |
| 지도 API·위치 기반 검색 | 비용·키 관리, 위치 권한 | 지도 서비스 선정, 약관 검토 |
| 실시간 영업·좌석·가격 정보 | 신뢰할 수 있는 출처 없음 | 공간과의 제휴·데이터 연동 |
| 이미지 업로드(모임·프로필·공간 사진) | 스토리지 RLS, 부적절 이미지 심사, 저작권 | 스토리지 정책, 신고·삭제 흐름 |
| 공간 운영자 계정·공간 직접 등록 | 사업자 검증 필요 | 검증 절차, 권한 모델 |
| 모임장이 확정 게스트를 내보내기 | 악용 가능성, 분쟁 처리 필요 | 사유 기록, 이의제기 절차 |
| 이용자 간 차단 | MVP 규모에서 신고로 대체 | 차단 시 노출·신청 규칙 정의 |
| 후기·평점·매너 점수 | 보복성 평가·명예훼손 위험 | 평가 정책, 신고·삭제 절차 |
| 반복 모임(매주 같은 시간) | 생성·수정 규칙 복잡 | 일정 반복 규칙 |
| 탈퇴 계정 자동 삭제(Edge Function, service role) | 현재 수동 절차로 충분 | 보관 기간 확정, 서버 측 비밀키 관리 |
| 다크 모드·테마 전환 | v3 기준 테마는 잉크 블랙 단일 | 디자인 결정 |
| 대전 외 지역 확장 | 런칭 지역 한정 | 권역 데이터 추가(테이블 구조는 확장 가능) |

## 2. 기술 개선 후보

- 목록 페이지네이션을 offset에서 keyset(`start_at`, `id`)으로 전환 — 데이터가 늘어 중복·누락이 생길 때.
- 검색 성능: `pg_trgm` 인덱스 — 검색량이 늘 때(PGlite 테스트 호환성 확인 필요).
- 자동 접근성 검사 도구(axe 계열) 도입.
- 오류 수집 도구 도입(개인정보처리방침 갱신 필요).
- `_headers` 빌드 시 생성 스크립트(환경별 CSP) — Phase 5에서 결정.
- 폰트 직접 호스팅(외부 CDN 의존 제거).
- 감사 로그·신고 기록 보관 기간 경과분 정리 작업.
- 공간·카테고리 변경 이력 감사 로그(현재는 `updated_at`만).
